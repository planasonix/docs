## What is a credit?

One credit is one CN core-hour of metered query and load CPU: one hour of processing power. Simple queries use a fraction of a second; big scans use more.

## Monthly allowance

| Plan | Credits per month |
| --- | ---: |
| Professional | 250 |
| Premium | 500 |

## What can credits cover?

**Estimate:** 250 credits covers roughly 900,000 typical dashboard queries, or about 180,000 heavy analytical queries, per month.

**Estimate:** 500 credits covers roughly 1,800,000 typical dashboard queries, or about 360,000 heavy analytical queries, per month.

These query examples are estimates, not a guarantee, based on typical dashboard queries using about 1 CPU second and heavy analytical queries using about 5 CPU seconds. Estimates will be refreshed from real usage.

Only production runs count toward your Analytics Pack credits.

Usage alerts at 50%, 80%, and 100% are advisory. There is no hard cutoff.
